Microsoft Publisher is discontinued: what to do with your .pub files

Key dates. Microsoft removed Publisher from Microsoft 365 subscriptions on October 1, 2026. Support for the last boxed versions (Office 2021 and Office LTSC 2021) ends on October 13, 2026. Microsoft 365 subscribers can no longer open or edit .pub files in Publisher; people with a boxed version can keep using it, without updates.

If you still have Publisher installed

Do the conversion now, while it still opens your files: File › Save As › PDF. For many files, Microsoft publishes a PowerShell script (Convert-PubFileToPDF) that drives Publisher to convert a whole folder — it only works on Windows with Publisher installed.

If you no longer have Publisher

  • In your browser, privately: PubRescue converts .pub files to PDF on your own device — nothing is uploaded. Free one file at a time; whole folders for a one-time fee.
  • Free desktop software: LibreOffice Draw opens most .pub files and exports PDF. It is a large install (several hundred MB) and converts files one at a time unless you use the command line.
  • Online converters: many websites convert .pub to PDF for free, but your file is uploaded to their servers — avoid them for documents with personal data.

If you need to edit the content

Convert to PDF first, then open the PDF in Word or import it into Canva: both turn PDF text into editable text, with some layout changes. For new documents, Microsoft suggests Word for cards, labels and calendars, and PowerPoint for posters and signs.

Quick checklist for an archive

  1. Gather every .pub file in one folder (with sub-folders by year if you like).
  2. Convert everything to PDF — PDF is the safest long-term format.
  3. Keep the original .pub files next to the PDFs.
  4. Open a few PDFs to check pictures and special characters.
