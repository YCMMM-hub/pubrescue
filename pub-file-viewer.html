PUB file viewer: open and view a .pub file

A .pub file is a Microsoft Publisher document. There is no simple built-in viewer for it: Word, Google Docs and Mac Preview can't open it, and since Microsoft removed Publisher from Microsoft 365 in October 2026, most people no longer have the one program that could.

The easiest way to view a .pub file is to turn it into a PDF — which every device can open — right in your browser. PubRescue does exactly that, and your file is never uploaded.

Open your .pub file now — free for one file at a time, nothing leaves your device. Open the viewer

View it in three steps

  1. Open PubRescue in any browser (desktop or phone).
  2. Drag the .pub file onto the page, or tap to pick it.
  3. In about a second you get a PDF you can read, print or save.

Opener vs converter: same tool

"Viewing" a .pub really means rendering it somewhere you can read it. PubRescue renders it to PDF locally, so the viewer and the converter are the same one-click action. If you specifically need the file for editing or archiving, see convert Publisher to PDF and open a .pub without Publisher.

On phone, Mac, Chromebook or Windows

Because it runs in the browser, PubRescue works on iPhone, Android, macOS, Chromebook, Windows and Linux. Platform guides: Mac, Chromebook.

Why not an online viewer that uploads?

Most free online .pub viewers send your file to their servers. For a personal document, a quote or a contract, that's a privacy risk. PubRescue keeps the whole thing on your device.
